# IE 5324 — Homework 5 Interactive Learning Studio

Self-contained, step-by-step interactive learning interface for **IE 5324 (Advanced Economics of Systems)** Homework 5.

## Included Modules
- **Start:** Big-picture overview, 3 core basics (MARR, Newnan factors, EUAC vs. NPW), and what the final comparison response is doing
- **Q1:** Robot Economic Life & Minimum EUAC interactive slider and chart
- **Q2:** Existing Crane Replacement, sunk-cost trap, and year-by-year Marginal Cost simulator
- **Q3:** Real Interest Rate (Fisher formula) purchasing-power playground
- **Q4:** Inflation + 5-Year MACRS Tax Shield + After-Tax NPW 5-domino year inspector
- **Q5:** Capital Budgeting ($1.8M) interactive budget packer and Opportunity Cost of Capital
- **Q6:** University WACC weighting assumption switcher (4.77% vs. 5.83%)
- **Q7:** Incremental Benefit/Cost Ratio (ΔB/C) 2-round tournament and NPW proof
- **Q8:** Current Ratio, Quick Ratio, and Working Capital account filter
- **60-Sec Cheat Sheet:** Quick formula, answer, and 7-step handwritten submission guide

## View Live on GitHub Pages
1. Upload `index.html` and `README.md` to your repository root (or push via Git).
